启动
将整个 PanXu 文件夹放到你有写入权限的位置，双击 PanXu.exe。
请保留同目录的 _internal 文件夹；不要只复制单个 EXE。
无需安装 Python，无需管理员权限。原生窗口使用 Microsoft Edge WebView2
Runtime 和 Windows .NET Framework；缺失时可先用下面的浏览器方式启动。
本程序不会自动安装系统组件。

首次使用
分析结果提供建议清单与全部项目两种视图，文件也可查看已扫描的目录结构。
用途、建议、原因和影响直接分区显示；勾选决定实际确认范围，可以批量执行、暂停和取消剩余项。
启动项、服务、进程、软件和文件共用这一流程，确认时分别列出具体动作与数量。
当前运行模式统一显示在窗口顶部，操作名称保持普通使用时的表达。
在首页选择清理 C 盘、清理某个磁盘、清理某个目录或查找重复，需要时选择位置。连接支持工具调用的
自定义模型后，助手会按需查看目录、核对软件、比较重复并提出方案。
点“保留这项”或补充要求，助手会根据你的选择继续调查并更新方案。
普通文件、图片、文档、安装包及未知临时文件必须由你明确选择，
不能仅凭名称、体积或旧日期自动认定可以清理。
确认后逐项记录处理与核验，再把结果反馈给助手。任务和选择可在重开后继续。
文件、目录、启动项、服务、后台应用和软件列表均可分析单项、勾选项或当前筛选列表。
分析选择不表示同意处理；助手提出方案后，再明确选择并确认。
目录支持智能按需、只看概况与逐项详细的调查要求。
助手可按需读取内置经验指导，并提出选项问题；可以选择、自由补充或暂不回答。
在用途建议的“自行处理”中可由你直接确认操作，程序核验后会把结果反馈给助手，
无需助手重新提出删除命令。当前仍只完成模拟记录，实际文件保持不变。
未连接模型时仍可在“我的文件”检查目录、手动选择与核对重复。
文件列表每页按需载入 50 项，搜索和换页保留选择；这不是全盘无用内容的完整清单。
设置可选择常见服务商预设，也可使用自定义服务和高级参数。
“保存并测试”使用固定测试数据验证完整工具调用往返，不发送扫描清单。
已核实的应用缓存可以获得规则建议；系统、凭据和项目保护仍优先生效。
目录扫描、磁盘信息、后台和软件清单均来自本机只读采集。
内置经验指导按需读取；助手还能查询只读内存/分页/休眠配置，以及当前任务范围所在卷与回收站统计。
这些是有时间和范围的证据，未知字段需继续核实，不会因此扩大清理范围或获得真实操作能力。

当前操作边界
本版本保留模拟执行边界。计划、执行、撤销、卸载及后台操作只写入模拟记录，不会实际删除、
移动用户文件、卸载软件、终止进程或修改系统设置。
本版本的预演结果不代表实际释放空间，实际释放量始终为零。
缓存和所有权标记只供建议，不构成执行授权。软件操作不授权删除其用户资料。
普通权限即可使用；程序以 asInvoker 运行，不申请管理员权限。

外观和开发模式
默认跟随 Windows 的浅色/深色设置并自动切换，也可在设置中固定深色或浅色；偏好随本机数据保存。
右侧开发面板默认关闭，可从设置打开或按F12切换。
记录开发通信和实时显示分别控制，可选择模型对话、技能和工具详情。
通信默认按角色显示可读正文；系统说明、任务事实、工具参数与结果分开展开，原始JSON按需查看。
软件、开机启动、文件和文件夹提供本地图标，不能识别时显示类型图标；图标不代表发布者认证。
开启记录后可能保存本地任务元数据；密钥、鉴权头、内部推理和协议私有续接不会记录。

数据和隐私
首次运行会在 PanXu.exe 同目录创建 userdata 文件夹，保存本地清单、
模拟历史和模型设置。可连同整个 PanXu 文件夹一起备份。
发布包不附带测试数据库、扫描记录、用户文件或任何模型 API 密钥。
未配置模型时不会向模型服务发送请求。
配置后只发送授权范围内的清单元数据；完整路径发送默认关闭，不上传文件内容。
重复校验会在本地有界读取文件计算哈希，字节内容不会发送给模型。
任务目标、用户反馈、选择、方案、历史事实和扫描进度保存在本机。
更换模型后根据这些资料重新建立上下文，不保存或移植提供方私有思考与协议签名。
大目录检查支持有界批次与持久分页；未完成枚举在进程重启后可能重新枚举，已存条目保留。
单次索引最多100000条，达到上限仍表示部分检查，需要缩小范围；目录观察不直接授权整组处理。
历史事实每任务最多300条、全局载荷32MiB；旧观察不替代处理前核对。
Windows 上的 API 密钥使用当前用户的 DPAPI 保护；换电脑或换 Windows
用户后需要重新输入密钥。模型可调查并提交方案，只有用户能确认处理。
开发模式可在设置中单独开启，查看实际请求、回复、工具定义、调用及结果。
仅记录启用后的通信，记录有数量和体积上限；密钥和协议内部推理不记录。
开发记录只保存在本机，可能含清单信息，不随发布包分享。
发布验证使用本机模拟模型接口；没有代替你验证真实模型服务的鉴权或兼容性。

可选启动参数
在此文件夹打开普通终端，可执行：
  .\PanXu.exe --browser
    使用默认浏览器访问本机页面；结束时在任务管理器关闭对应 PanXu 进程。
  .\PanXu.exe --data-dir "E:\PanXuData"
    将程序自己的记录放到指定目录。
  .\PanXu.exe --port 8765
    使用指定本机端口；默认自动选择空闲端口。
  .\PanXu.exe --headless --port 8765 --data-dir "E:\PanXuData"
    仅启动本机 HTTP 服务，供诊断或自动验收使用。

迁移和移除
正常关闭窗口后，可以移动或删除整个 PanXu 文件夹。
如果使用了自定义 --data-dir，其数据目录需要单独管理。
原生窗口关闭后，本机服务随程序退出。浏览器模式需要另行结束 PanXu。

构建
项目内 build.ps1 使用当前已安装的 Windows x64 Python 3.14、PyInstaller、
pywebview 和 psutil，生成 dist\PanXu 目录，并将静态打包检查写入
verification\package.json。脚本不安装依赖，不提权，不覆盖已有发布目录。
源码冻结并完成本轮测试、界面和本机验收后，使用 verification\finalize.py
生成带版本号的 ZIP、acceptance.json 和 source-manifest.json。它记录本轮证据，
不会把截图存在或外部传入的测试数量当作已自动验证全部界面流程。

评分与文件视图
建议可带1到5分，分数越高越倾向清理；3分中立，未评分、明确跳过与暂不建议分开。
“建议清单”只列直接分析项；“目录结构（已扫描）”按需展开已保存范围并标注继承建议。
只有明确覆盖子项的目录建议才向下继承，子项明确保留优先；整体删除不能吞掉保留项。
调查后直接进入本轮清理清单；单文件与目录沿用同一流程。
4–5分仅用于初始化勾选草案，4分可在更多选项中关闭自动勾选；最终范围完全取决于勾选。
1–5分、已跳过、未评分、暂无建议可分别选择或取消，也能全选本轮已扫描范围。
勾选目录包含已观察子项；可取消具体子项，父目录显示半选，执行清单会排除这些例外。
每批最多500个实际目标，数量及尚未纳入本批的项目会明确提示，需要另行确认下一批。
点击模拟删除后先查看确认摘要，再开始执行；进度中可暂停、继续或取消。
取消保留已完成记录，未提交项取消；意外关闭后的活动批次标为已中断，不自动重放。
评分批量选择不会自动执行，所有删除仍只写模拟记录。

建议阅读
评分位于建议和文件列表的主要位置；先看短结论与本轮重点，再按需展开原因、影响和检查范围。
旧版长说明可展开阅读全文，原建议和模型来源继续保留。
接收新回复时仍显示最近一次完整公开回复，失败、取消或空回复不会覆盖它。
普通上下文和工具观察使用精简可读文本；原生API信封、工具定义与类型参数保留协议格式。
完成一批操作后直接返回结果；继续调查在更多选项中，执行本身不再自动请求模型。

本地查重与页面导航
查找重复文件使用本地目录枚举、大小分组与SHA-256，不需要模型。
Windows不提供每个文件的现成通用哈希，核验时读取同大小候选的内容，不上传。
没有第二轮逐字节比较；相同内容不自动表示其中一份可以删除。
硬链接单独说明，保护、链接、云占位与变化项目跳过；预算与省略明确提示。
重复结果只读，不生成评分或删除授权，也不替换已有整理任务和扫描清单。
默认读取上限2GiB，可改1/2/4/8GiB；条目、深度及协作时间也有上限。
返回操作统一在左上角。常用结论和提醒直接显示，分析详情、补充要求与过程分别进入单独页面。
