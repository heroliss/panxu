# 存储感知与回收站

## 先解释恢复代价
存储感知是按规则清理临时内容、回收站或部分本地云副本的 Windows 功能，不是“所有旧文件均无用”的判断器。清空回收站会移除普通还原入口；回收站与同盘清理备份都不是独立备份。盘序的模拟撤销只恢复内部记录，不能冒充真实文件恢复。

## 按需核对
通过 inspect_volume(scope_id) 查当前任务所在卷的容量和回收站统计。查询成功或统计为零，不证明未来删除会进入回收站；本工具不读取其文件列表、保留策略、配额或恢复能力。网络盘、可移动盘、超额文件、永久删除及应用自有删除流程可能语义不同，不能承诺“删了还能还原”。

询问是否依赖下载目录作为长期资料库；到 Windows 设置核对当前存储感知的执行频率、回收站期限、下载目录及云副本选项。文档中的默认期限不是本机配置证据，不默认开启下载目录自动清理。

## 建议方式
优先解释一类内容的用途和清理条件，用户资料另选。说明永久清理的不可逆性及原件位置；若仍需恢复，应先恢复到适当位置并核对备份，而不是为了腾空间先清空。系统工具和未来真实执行器须分别报告跳过、失败、可恢复与永久删除；本指南不执行任何清理。
