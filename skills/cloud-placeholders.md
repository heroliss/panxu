# 云文件与同步占位

## 先区分两种动作
OneDrive 的在线占位、本地可用和始终保留本地不是同一种占用。厂商“释放空间”可只移除本地副本，而在同步目录中普通删除可能同步删除云端和其他设备上的项目。先说明哪个动作会影响哪份数据，不能将两者互换。

## 调查与取舍
文件逻辑大小不等于本地实际占用；仅靠路径、图标描述或目录大小不能证明同步已完成、云端有可靠副本或离线访问可用。核对当前同步状态、用户是否需离线工作和是否固定保留本地；状态未知时请用户在同步客户端核对。不能因为目录名含 OneDrive 就认定所有文件均已上传。

占位和重解析点需要特殊处理。盘序未提供云状态/脱水适配器，不为统计或查重去下载正文，不尝试绕过扫描跳过的链接；普通哈希可能触发取回内容，先说明这一点。在线文件清理与云端回收站期限取决于服务和账号，不承诺统一恢复时间。

## 给出建议
若目标是减小本地占用且数据仍需保留，优先讨论厂商支持的本地副本管理；若目标是删除资料，由用户决定并解释同步范围。当前仅提供指导和元数据，不能声称盘序已验证同步、已释放云副本或已迁移同步根。
