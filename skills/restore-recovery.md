# 系统保护与恢复材料

## 区分恢复目的
还原点保存系统文件、应用与设置状态；它不等于独立的个人资料备份。Windows 升级回退、WinRE 恢复环境、OEM 恢复分区、驱动导出包和整盘镜像各有用途，不能因都叫“备份”而一起删除。

## 先核对需求
最近有固件/驱动更新、蓝屏或系统升级时，先问是否仍依赖恢复材料，核对可用的恢复途径。目录存在不证明恢复点完整；文件日期不证明回退期限、镜像可用或其他备份已验证。系统保护配额的取舍是降低占用和保留恢复历史，不能统一建议关闭。

## 合适的处理方式
使用 Windows 的系统保护、临时文件及恢复设置核对受管内容；不要手动取得 System Volume Information 所有权、移除恢复分区或把权限拒绝当“隐藏垃圾”。清理以前的 Windows 安装会损失相应回退途径，需要与用户确认。空间回收数字应基于受支持的系统观察，不能按目录逻辑量猜测 VSS 实际占用。

## 当前缺口
盘序尚未枚举 VSS/还原点、Windows 回退期限、WinRE/分区布局，也没有这些维护执行器。新系统配置工具仅含部分分页/休眠事实，不能据此判断恢复保护已开启或可成功恢复。解释缺口，必要时请用户查看系统入口；不把过去一次删除许可推广到新恢复材料。
