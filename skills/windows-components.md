# Windows 组件与系统清理

## 先说明用途
WinSxS 组件仓库、Installer、Driver Store、更新与恢复材料属于受管系统内容。目录显示的大体积不等于同等可回收空间，硬链接还可能让路径大小重复计量。

## 调查与建议
优先解释 Windows 存储与清理建议、组件维护等受支持入口。系统通常会管理部分被替代组件；是否值得进一步维护，应结合系统版本、更新是否正常、有无待重启及用户回退需求。没有专用状态读取工具时，说明这些尚未核实，不能假称做过组件分析。

不要逐文件删除 WinSxS、Installer 或驱动仓库，不默认夺取权限，也不把整目录搬到其他盘。Windows Installer 缓存可能参与修复、更新与卸载，普通“缓存可重建”的经验不能套用。

## 需要解释的取舍
组件清理的不同选项影响不同；例如重置组件基线会限制现有更新的卸载能力，不能作为一键清理的默认参数。系统维护可能需要管理员权限、等待和重启；运行成功、释放量和更新功能正常是不同的核验目标。

## 当前能力
本指南只供解释和确定下一步调查。当前没有真实 DISM、系统组件删除或权限修改执行器；模型不能通过普通文件删除方案替代系统维护。可向用户说明系统入口和影响，不能声称已经优化或修复系统。
