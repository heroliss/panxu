# 分页文件与虚拟内存

## 先解释用途
分页文件为部分内存页提供磁盘后备，并影响系统提交上限及崩溃转储能力。它是系统配置的一部分，不能按普通垃圾删除；已分配大小也不等于当前正在使用量。

## 如何调查
先确认用户看到的是设置值、重启后实际生效文件，还是系统创建的临时页面文件。需要 RAM、提交峰值、转储类型、各卷剩余空间及页面文件配置/实际分配证据；磁盘可用性、权限、路径与重启状态也可能影响配置。当前没有这些读取工具时，不能凭目录扫描断言原因或给出“最佳大小”。

## 建议的取舍
大小取决于工作负载的提交需求和转储要求，不能把 C 盘固定 1–2 GB、RAM 的固定倍数、每个盘都开启或全部关闭当通用方案。可把系统管理作为需要比较的起点，同时说明它可能增长，不能预报每个盘一定占多少。

若考虑改到其他盘，要调查磁盘稳定性、持续可用性、剩余空间、I/O 竞争及所需转储条件；分区盘符不同不一定是不同物理硬盘。不能为了腾空间把分页放到存在异常或可拔出的存储上，也不能在无证据时承诺一定提速。

## 当前边界与核验
分页配置不是本版本的真实执行能力。不直接删除 pagefile.sys，不把用户偏好当配置授权。后续若有专用适配器，应保存原设置，明确重启要求，再核对实际配置与提交余量；不能因设置窗口显示已选中就宣称生效。
