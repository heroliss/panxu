# 下载与旧安装包

## 区分几种东西
下载目录可能同时有安装包、便携程序、解压后的在用应用、个人作品、资料及分卷压缩包。EXE/MSI 扩展名不是“已安装、可删”的证明；exe 也可能就是用户每天启动的程序。

## 按需取得证据
先看目录结构、版本与同组文件，再参考安装登记和发布者线索。核对安装来源、以后能否可靠取得、是否需要离线重装；清单不全时不宣称已找到所有版本。压缩分卷按完整一组说明，不能零散删除后留下不可用归档。

## 减少决定负担
模型可以按“可重新取得的旧安装包”“可能在用的便携程序”“个人资料”“需要补证据”分组解释并提出少量建议。用户下载和创建的文件仍由用户决定；询问一个会影响整组去留的问题，比逐文件反复询问更有用。用户只授权删除安装包，不表示也授权删除解压程序或整个下载目录。

## 系统边界
用户保存的离线安装包与 Windows Installer 缓存不是同一类。Windows 目录下的 Installer 文件可能参与软件更新、修复和卸载，不能按扩展名清理；已安装应用应先走正规卸载指南。

## 结果说明
建议是去留辅助，不把“旧”或“重复下载”当成执行许可。处理前仍核对文件身份与当前选择；模拟记录不能说成实际释放空间，下载到别处也不能推断原文件已安全备份。
