# 旧备份与系统升级文件

## 先区分恢复用途
个人镜像与历史资料、清理前临时备份、驱动导出包、应用安装介质和 Windows 升级回退文件有不同用途。GHO、备份日期或目录名字不能证明它已无用。旧镜像也可能是用户明确要求保留的唯一历史副本。

## 应调查什么
核对来源、创建原因、覆盖哪些内容、有无其他可用副本及恢复方法，必要时询问恢复需求。没有完整性或可恢复性证据时，不声称备份可靠。用户之前一次清理的同意，不自动授权本次所有同名、旧账号或备份目录。

## 给出有条件的建议
专门用于短期回滚的清理备份，可以在原操作确认正常、用户不再需要该恢复点时建议删除。不要写死“过两天都可以删”，也不能仅因仍保留当前驱动就推断所有导出包无用。设备正在使用的 Driver Store 是系统受管驱动仓库，不能把它当用户导出的备份目录直接清掉。

## Windows 升级回退
Windows.old 与以前的系统安装关系到返回旧版本的能力。先核对升级情况、用户资料和是否仍要回退；使用系统清理入口，明确删除后该回退途径会消失，不等同普通回收站撤销。不从目录存在或时间推断当前仍有回退资格。

## 当前边界
模型可组织证据和建议，但不能把历史经验当当前机器状态；盘序尚无真实系统回退、驱动包删除或镜像恢复执行器。恢复能力未验证就如实标为未知。
