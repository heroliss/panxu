# 盘序 · Windows 磁盘清理助手

盘序帮你把 Windows 电脑上占空间的东西找出来、讲清楚、安全地清理掉：系统和应用的垃圾缓存、陌生的大文件夹、你自己忘了的旧文件和安装包、重复文件、不再用的程序，以及拖慢开机的启动项和服务。

点一下「一键体检」，盘序会给出一份清理方案：放心清理的项目已经勾好，其余的每一项都写明是什么、为什么列出来、清理后会怎样，并给出 0–10 分的建议清理度。常见情况由内置规则直接判断，规则不认识的交给 AI 模型（默认 DeepSeek）给出建议；任何一项都可以「问 AI」。每一次修改都记在操作记录里，能撤销的都可以撤销。

> 当前版本 **1.1.0**，是第一个正式版本。更新内容见 [CHANGELOG](CHANGELOG.md)。

## 下载和使用

1. 在 [Releases](https://github.com/heroliss/panxu/releases) 下载 `PanXu-1.1.0-win-x64.zip`，解压到任意文件夹（例如 `D:\工具\PanXu`）。
2. 双击 `PanXu.exe`。不需要安装，不写注册表的安装信息。

**系统要求：** Windows 10 或 11（64 位），以及 Microsoft Edge WebView2 运行时（Windows 11 自带；Windows 10 一般随 Edge 已经装好）。

**第一次用，建议先在演练环境里熟悉：** 在命令行里运行 `PanXu.exe --sandbox`。盘序会生成一台模拟的「用了几年的电脑」，所有删除、禁用、卸载都只发生在这台模拟电脑里，窗口顶部有提示条，可以随时还原或重建。

**需要管理员权限的项目**（Windows 临时文件、更新缓存、旧版 Windows、服务等）会标明，点「以管理员身份重启」才会弹出 UAC，平时以普通权限运行。

**数据存放在** `%LOCALAPPDATA%\PanXu`：设置、操作记录、AI 缓存和日志（`panxu.log`）。不想用了，删除程序文件夹和这个文件夹即可。

## 能做什么

| 页面 | 做什么 |
|---|---|
| **首页** | 系统盘容量和「一键体检」：依次检查垃圾、系统盘空间、我的文件、重复文件，再让 AI 复核，生成分三组的清理方案（放心清理 / 建议你看看 / 仅供了解）。可以按分数一键勾选，展开任何一项查看依据。清理后显示真正释放了多少、多少在回收站、哪些没完成以及原因。 |
| **垃圾清理** | 39 项内置规则：临时文件、更新缓存、错误报告、崩溃转储、浏览器和应用缓存、开发工具缓存、显卡着色器缓存、回收站、旧版 Windows、组件存储清理等。只清理公认可以重建的内容。 |
| **空间分析** | 扫描整个磁盘或某个文件夹，用占用图和文件夹树看空间都在哪里，已知位置会标注用途。规则不认识的文件夹（不论大小，从大到小一批批）可以交给 AI 判断。 |
| **我的文件** | 在你的个人文件夹里找：已装程序的安装包、没下完的文件、解压过的压缩包、同一文件的多个版本、很久没动的大文件、下载文件夹里的旧文件、空文件夹。只会移到回收站。 |
| **大文件** | 列出最大的文件，可以按类型和修改时间筛选；可以让 AI 说说每个文件可能是什么、能删、该留还是适合归档。 |
| **重复文件** | 逐字节比对找出内容完全相同的文件。程序和代码工程里的副本会标出位置，并在工程里查有没有文件用到它；可以让 AI 说说每组哪一份更适合删除。 |
| **应用** | 已安装的程序、大小、安装日期、最近运行时间，AI 说明哪些可以卸载。卸载使用程序自己的卸载程序，卸载后可以查找残留。 |
| **开机与服务** | 启用或禁用开机启动项（和任务管理器的「启动应用」是同一套开关），修改第三方服务的启动方式。AI 会结合「它是哪个应用的一部分、这个应用你是否正在用」给出建议。 |
| **操作记录** | 每次清理、删除、修改的时间、内容、释放的空间和失败的项目；对开机项、服务和系统设置的修改可以撤销。 |
| **AI 顾问** | 任何页面、任何一项都可以「问 AI」，可以追问。 |

## 安全承诺

- **你的文件只由你决定。** 个人文件、来源不明的文件不会被自动勾选，只会移到回收站。AI 的建议只影响一项放在哪一组、附什么说明，不会扩大可以处理的范围。
- **两种删除方式分开。** 垃圾清理规则里的缓存和临时文件直接删除；其余所有项目默认移到回收站。回收站放不下的东西，Windows 会先问你是否直接删除；如果你选了直接删除，盘序会如实告诉你哪些已经彻底删除、不能从回收站还原。
- **受保护的位置删不了。** Windows 目录、程序目录中的系统部分、各个用户文件夹的根目录、凭据和证书目录等，用户和 AI 都删不了；包含受保护文件夹的上级目录也会被拒绝。你也可以在设置里添加自己的排除目录。
- **不穿越链接，不碰云端文件。** 扫描和删除不会进入目录联接和符号链接；OneDrive 等云端占位文件不会被读取（读取会触发下载）。
- **规则自带保险。** 太新的临时文件不删；正在使用的文件跳过；相关程序（如浏览器）还开着时整项跳过。
- **中途关闭也不会乱。** 清理进行中关闭窗口会先询问，并在当前文件处理完后停下；被强行结束时，操作记录会标明「没有完成」以及已经处理了多少。

## AI 与隐私

程序决定看什么、发什么，模型只负责判断，不会自己调用工具或读取电脑上的东西。发送的内容都经过匿名化（用户名替换成 `%USERPROFILE%` 等），开始分析前会列出将要发送的内容：

- **空间分析：** 规则不认识的文件夹的摘要（大小、文件数、修改时间、主要子文件夹、文件类型分布、最大的几个文件名），不上传文件内容。
- **我的文件、大文件、重复文件：** 文件名、所在文件夹、大小和日期，以及盘序查到的情况。文档开头的内容只有在设置里允许、并且这一次确认框里再次勾选时才会发送。
- **开机与服务、应用：** 名称、程序路径、发布者，以及盘序查到的事实（是否正在运行、是哪个应用的一部分、这个应用现在是否开着）。

支持 DeepSeek、Kimi、智谱 GLM、通义千问、硅基流动、OpenAI、Anthropic Claude、本地 Ollama，以及任何 OpenAI 兼容接口。API Key 用 Windows 账户加密（DPAPI）保存在本机。分析结果缓存 30 天，重复分析不消耗额度；每次分析都有请求次数上限。不配置模型也能使用，只是没有 AI 复核和说明。

## 常见问题

**「放心清理」为什么不包括我的文件？** 你的文件只由你决定，盘序从不自动勾选它们。首页可以打开「包括我的文件」，按分数一起勾选。

**建议清理度怎么看？** 8–10 分建议清理，5–7 分可以考虑，0–4 分看你需要。展开任何一项都能看到评分依据：绿点是支持清理的证据，琥珀色的是需要注意的理由，蓝色的是 AI 的话，最后一行写明为什么勾或没勾。勾选门槛可以在「设置 > 一键体检」里调整。

**移到回收站以后空间没变多？** 回收站里的文件仍然占用空间，需要时可以还原；清空回收站后才真正释放。首页清理结果会分开显示「已释放」和「在回收站」。

**AI 的判断一定对吗？** 不一定。所以 AI 不能扩大处理范围，也不能越过保护规则；没把握的、属于正在使用的程序的、最近还在改动的，都不会自动勾选。觉得不对，可以「问 AI」追问，或者直接不勾。

