# 盘序：Win11 空间与后台管理

盘序用简单的中文建议帮助普通用户整理空间、了解后台程序。主流程是“开始检查 → 查看建议 → 确认处理”；程序先说明结论，需要了解原因、影响和技术依据时再展开。

当前开发构建启用了测试保护：界面按正式产品设计，所有处理仍只写入本地记录，**不会删除文件或修改系统**。窗口顶部会显示一条保护提示，不提供真实执行开关。

代码基地：[GitHub · heroliss/panxu](https://github.com/heroliss/panxu)（当前为私有仓库）。

## 启动

- 本机直接双击 `启动盘序.cmd`，或打开 `dist/PanXu` 后双击 `PanXu.exe`。
- 便携程序需要保留整个 `PanXu` 文件夹，包括 `_internal`。不需要管理员权限。
- 源码启动：Python 3.11+，安装 `requirements.txt` 后执行 `python run.py`。缺少 pywebview 时使用本地浏览器；缺少 psutil 时进程盘点提示不可用。
- 自动化测试服务：`python run.py --headless --port 3558 --data-dir verification/ui-data`。服务仅监听 `127.0.0.1`。

## 可以体验

1. 首页只有一个主要入口“开始检查”，读取当前用户的常见缓存位置、后台和软件信息，不自动遍历全部磁盘或读取个人文件内容。首次打开没有样例资料，旧版开发样例会自动从清单中移除。
2. 建议分为“建议处理”“你的文件”“建议保留”。只把核实为可再生成的应用缓存默认选中；下载资料、个人作品、未知用途文件始终由用户选择。
3. 在“我的文件”中指定目录后检查。默认最多 25,000 个条目、12 层；高级选项可调整，首版上限 100,000 条。目录不完整时不能整组处理。
4. “后台与软件”默认展示结论，完整清单需要展开。后台最多采集 300 个进程；软件只覆盖传统桌面卸载注册项，非所有 Store 应用。Run 注册项不等于已确认启用。
5. 各页选择可以组合成一批，先显示处理原因和影响，再确认。保护项不可选；推荐批次的后端校验也禁止夹带个人文件。
6. “处理记录”可撤销工具内部的处理状态；不会把预演体积说成实际已释放空间。
7. 明确选择文件后可做有预算的 SHA-256 重复校验。硬链接单独解释，内容相同不等于应该删掉。

真实磁盘空闲量、文件逻辑估算和进程工作集分别显示。**模拟执行的实际释放量始终为 0**。内存工作集包含共享数据，不表示能够释放等量物理内存。

## 自定义模型与 harness

在“设置”的“智能建议”中填写兼容服务地址（通常以 `/v1` 结尾）、模型 ID 和可选 API Key。远程使用 HTTPS；HTTP 仅允许本机回环服务。首版只支持 Chat Completions 兼容协议，并非所有服务商的专有参数。

- 没有配置模型时，使用本地规则解释，不联网。
- 已配置模型时，“开始检查”后请求结构化的建议与通俗解释，最多覆盖 100 个候选条目，并明确报告覆盖范围。模型输出需验证 ID、动作、个人资料和保护策略，不能把自由文本直接当作操作指令。
- 个人文件始终保留用户决定权；模型建议无法取消此要求。未知服务、软件和进程的只读清单不提供足够证据时，不自动停止或卸载。
- 只提供已采集的元数据；默认隐藏完整路径，不读取或上传文件正文、Cookie、密码、进程命令行。
- 最多 4 轮模型响应、8 次工具调用；每个请求有超时和体积上限。
- 模型只有 `list_items`、`inspect_items`、`summarize_inventory` 三个只读工具，范围绑定当前提供或选中的条目。它不能执行 shell、扫描额外目录或应用计划。
- API Key 在 Windows 下通过当前用户 DPAPI 加密后保存；非 Windows 仅驻留内存。公共设置接口不回显密钥。更换服务来源必须明确替换或清除旧密钥。
- 保护规则可以是目录片段或通配符，每行一条。它影响程序策略；自定义模型建议要求不能取消保护项。

本地状态在启动程序所在目录的 `userdata` 中；可使用 `--data-dir` 指定独立位置。状态含真实扫描路径，属于本机私有数据，不应随发布包分享。发布包未包含本机测试目录或模型配置。

## 实现与验证

- `diskpilot/scanner.py`：有界、只读、不跟随重解析点的扫描、项目识别和元数据版本验证。
- `diskpilot/windows.py`：注册表/CIM/psutil 只读采集，不暴露系统修改接口。
- `diskpilot/simulation.py`：冻结计划、保护规则、重复计量和 SQLite 模拟覆盖层。
- `diskpilot/llm.py`：提供方适配、密钥保护、上下文与工具预算。
- `diskpilot/recommendations.py`：规则与模型的建议整合、个人决定权及默认选择边界。
- `diskpilot/server.py`：仅本机 HTTP 服务，Host/Origin/CSRF 校验、静态资源白名单。
- `web/`：无需 CDN 或构建依赖的中文界面。

运行测试：`python -W error::ResourceWarning -m unittest discover -s tests -v`。
本机验收脚本：`python verification/run_local_acceptance.py`，输出只含数目、散列与判定，不含私人命令行或凭据。
`verification/` 保存测试结果、实际 Windows 窗口截图和打包校验。

## 当前限制与后续

此版用于反复测试交互和策略，**不能切换成真实删除模式**。未实现真实服务控制、进程结束、开机项禁用、正规卸载、浏览器隐私清除、跨盘迁移或回收站恢复。记录中的“撤销”只恢复工具内部状态。

未提供全局自启动枚举、所有服务依赖分析、实时文件锁审计、Windows 分配空间精确估计或性能优化保证。受保护目录中的源码/凭据会保守排除，未知用途需进一步确认。后续正式执行器应作为独立开发和验收阶段，不能通过开启隐藏配置绕过模拟限制。

跨盘迁移、扫描增量、软件知识库、更多缓存配方与浏览器适配器将沿用同一计划/验证契约逐步加入。首先保证每个操作都能说明来源、影响、执行结果和恢复能力。
