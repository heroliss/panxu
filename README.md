# 盘序 · Windows 磁盘清理助手

盘序帮你把 Windows 电脑上占空间的东西找出来、讲清楚、安全地清理掉：系统和应用的垃圾缓存、陌生的大文件夹、你自己忘了的旧文件和安装包、重复文件、不再用的程序，以及拖慢开机的启动项和服务。

点一下「一键体检」，盘序会给出一份清理方案：放心清理的项目已经勾好，其余的每一项都写明是什么、为什么列出来、清理后会怎样，并给出 0–10 分的建议清理度。常见情况由内置规则直接判断，规则不认识的交给 AI 模型（默认 DeepSeek）给出建议；任何一项都可以「问 AI」。每一次修改都记在操作记录里，能撤销的都可以撤销。

首页按「检查范围」和「分析选项」分区：每个磁盘可以单独勾选整盘检查，默认包含本地固定磁盘；用户目录、公共文件夹、已迁移的常用文件夹和添加的位置始终检查。「检查应用与服务」读取已安装的程序和第三方服务（默认开启）；查重下可选择是否比较不同磁盘的副本；AI 复核下可分别选择陌生目录与软件残留、个人文件、重复副本、开机启动项、应用卸载建议和第三方服务。这些选择会记住，**只控制首页体检**；单项工具和主动「问 AI」保持各自设置。

体检进行中可以切换工具页查看结果，完成的阶段会自动同步。再次点扫描会提示当前进度，不会同时启动另一项检查或清理；体检结束后，可在单项工具里按需要重新检查其他范围。窗口顶部与界面采用统一样式，保留拖动、缩放、最小化和最大化。

> 当前版本 **2.0.2**。更新内容见 [CHANGELOG](CHANGELOG.md)。

## 下载和使用

1. 在 [Releases](https://github.com/heroliss/panxu/releases) 下载 `PanXu-2.0.2-win-x64.zip`，解压到任意文件夹（例如 `D:\工具\PanXu`）。
2. 双击 `PanXu.exe`。不需要安装，不写注册表的安装信息。

**系统要求：** Windows 10 或 11（64 位），以及 Microsoft Edge WebView2 运行时（Windows 11 自带；Windows 10 一般随 Edge 已经装好）。

**第一次用，建议先在演练环境里熟悉：** 在命令行里运行 `PanXu.exe --sandbox`。盘序会生成一台模拟的「用了几年的电脑」，所有删除、禁用、卸载都只发生在这台模拟电脑里，窗口顶部有提示条，可以随时还原或重建。

**默认在启动时请求管理员权限**，Windows 会询问是否允许，以便一次体检覆盖系统项目。在「设置 > 启动与权限」可关闭；取消提权提示后仍会以普通权限打开。普通模式下也可以「以管理员身份重启」：保留已完成的扫描、AI 结论和勾选，只补查系统垃圾与应用使用记录，新发现的项目由你勾选。此前空间扫描里无法读取的目录仍标明缺口，可按需单独重扫。演练模式不请求真实提权。

**数据存放在** `%LOCALAPPDATA%\PanXu`：设置、操作记录、AI 缓存和日志（`panxu.log`）。不想用了，删除程序文件夹和这个文件夹即可。

## 能做什么

| 页面 | 做什么 |
|---|---|
| **首页** | 选择体检磁盘和分析项目，查看结果总览、各工具覆盖情况，并执行统一清理方案。长列表默认收起，可展开核对原因、排序和调整勾选；详情直接转到对应工具页，无需重扫。空间分析同时提供大文件结果；开启「检查应用与服务」时，方案也列出可以卸载的程序（逐个运行它自己的卸载程序）和可以改为手动启动的第三方服务。 |
| **垃圾清理** | 46 项内置规则：临时文件、更新缓存、错误报告、崩溃转储、浏览器和应用缓存、开发工具缓存、显卡着色器缓存、回收站、旧版 Windows、组件存储清理等。评分与首页一致，按明确的目录和文件白名单处理；不可恢复或影响回退的项目需单独确认。 |
| **空间分析** | 扫描整个磁盘或某个文件夹，用占用图和文件夹树看空间都在哪里，已知位置会标注用途。规则不认识的文件夹（不论大小，从大到小一批批）可以交给 AI 判断。 |
| **我的文件** | 默认查看你的常用文件夹、用户目录、公共文件夹，以及 C/D/E 等本地固定磁盘上的其他文件，找出旧安装包、没下完的下载、解压过的压缩包、多个版本、很久没动的大文件和空文件夹。只看不删，文件由你勾选后移到回收站。也可以选择一个文件夹单独整理。 |
| **大文件** | 列出最大的文件，可以按类型和修改时间筛选；可以让 AI 说说每个文件可能是什么、能删、该留还是适合归档。 |
| **重复文件** | 逐字节比对找出内容完全相同的文件，默认范围和首页体检一样（首页选中的磁盘和你的个人文件夹，跳过系统、程序和应用数据）。程序和代码工程里的副本会标出位置，并在工程里查有没有文件用到它；可以让 AI 说说每组哪一份更适合删除。 |
| **应用** | 查看已安装程序、占用、最近运行时间和 AI 卸载建议，使用程序自己的卸载程序。另有「软件残留与登记」，复用体检结果或单独查找，逐项查看依据并问 AI。 |
| **开机与服务** | 启用或禁用开机启动项（和任务管理器的「启动应用」是同一套开关），修改第三方服务的启动方式。AI 会结合「它是哪个应用的一部分、这个应用你是否正在用」给出建议。 |
| **操作记录** | 每次清理、删除、修改的时间、内容、释放的空间和失败的项目；对开机项、服务和系统设置的修改可以撤销。 |
| **AI 顾问** | 任何页面、任何一项都可以「问 AI」，可以追问。 |

「我的文件」默认会跳过系统、已安装程序、应用数据和缓存、其他账户、排除的目录、链接和云端占位文件。D/E 等本地固定磁盘不需要手动添加；可移动磁盘和网络位置不默认整盘查看，但桌面、文档等常用文件夹重定向到那里时仍会查看。可移动磁盘和网络文件夹等其他位置可以在设置里添加，或在「我的文件」中选择一个文件夹整理。达到本次文件数上限时会明确提示尚未扫完，可以选择文件夹分批整理。

## 安全承诺

- **你的文件只由你决定。** 个人文件、来源不明的文件不会被自动勾选，只会移到回收站。AI 的建议只影响一项放在哪一组、附什么说明，不会扩大可以处理的范围。
- **两种删除方式分开。** 垃圾清理规则里的缓存和临时文件直接删除；其余所有项目默认移到回收站。回收站放不下的东西，Windows 会先问你是否直接删除；如果你选了直接删除，盘序会如实告诉你哪些已经彻底删除、不能从回收站还原。
- **受保护的位置删不了。** Windows 目录、程序目录中的系统部分、各个用户文件夹的根目录、凭据和证书目录等，用户和 AI 都删不了；包含受保护文件夹的上级目录也会被拒绝。你也可以在设置里添加自己的排除目录。
- **不穿越链接，不碰云端文件。** 扫描和删除不会进入目录联接和符号链接；OneDrive 等云端占位文件不会被读取（读取会触发下载）。
- **规则自带保险。** 太新的临时文件不删；正在使用的文件跳过；相关程序（如浏览器）还开着时整项跳过。
- **中途关闭也不会乱。** 清理进行中关闭窗口会先询问，并在当前文件处理完后停下；被强行结束时，操作记录会标明「没有完成」以及已经处理了多少。

## AI 与隐私

程序决定看什么、发什么，模型只负责判断，不会自己调用工具或读取电脑上的东西。发送的内容都经过匿名化（用户名替换成 `%USERPROFILE%` 等），开始分析前会列出将要发送的内容：

- **空间分析：** 规则不认识的文件夹的摘要（大小、文件数、修改时间、主要子文件夹、文件类型分布、最大的几个文件名），不上传文件内容。
- **我的文件、大文件、重复文件：** 文件名、所在文件夹、大小和日期，以及盘序查到的情况。文档开头的内容只有在设置里允许、并且这一次确认框里再次勾选时才会发送。
- **开机与服务、应用：** 名称、程序路径、发布者，以及盘序查到的事实（是否正在运行、是哪个应用的一部分、这个应用现在是否开着）。

支持 DeepSeek、Kimi、智谱 GLM、通义千问、硅基流动、OpenAI、Anthropic Claude、本地 Ollama，以及任何 OpenAI 兼容接口。API Key 用 Windows 账户加密（DPAPI）保存在本机。分析结果缓存 30 天，重复分析不消耗额度；每次分析都有请求次数上限。不配置模型也能使用，只是没有 AI 复核和说明。

## 常见问题

**「放心清理」为什么不包括我的文件？** 你的文件只由你决定，盘序从不自动勾选它们。首页可以打开「包括我的文件」，按分数一起勾选。

**建议清理度怎么看？** 8–10 分建议清理，5–7 分可以考虑，0–4 分看你需要。展开任何一项都能看到评分依据：绿点是支持清理的证据，琥珀色的是需要注意的理由，蓝色的是 AI 的话，最后一行写明为什么勾或没勾。勾选门槛可以在「设置 > 一键体检」里调整。

评分依据包括缓存的重建成本、最近是否有改动、安装包与已装版本的关系、重复内容是否已校验，以及里面是否有个人资料。体积大或日期旧本身不会让文件变成高分垃圾；AI 的信心也不会直接变成清理分数。ZIP 只有全部条目的大小与 CRC 校验一致才算已验证解压，校验不了的留给你确认。

一键体检的重复文件阶段最多列出 40 万个符合大小条件的文件、读取约 16 GiB 用于比对，避免大盘长时间连续读取；到上限时会提示尚未全部比对，已列出的副本都完成了内容校验。「重复文件」页查找整个磁盘时用同样的上限，可移除磁盘、选择具体目录继续完整查找。空间分析会统计所选磁盘中的系统、程序占用，但不会因此建议删除；个人文件与重复文件阶段仍会跳过系统和应用数据等位置。体检结果同步到垃圾清理、空间分析、大文件、我的文件、重复文件、应用和开机与服务页，勾选与首页共用。未启用的项目明确标注为未检查，工具页可能保留此前的结果。

内容比对另设约 3 分钟预算，工程引用检查共用 256 MiB / 30 秒预算（不含前面的目录枚举，单次磁盘读取可能延迟返回）。读不完、文件无法读取或用户排除的位置，不会被当成「确定没有引用」，相关副本会保守评分。单独选择目录查重复时不受体检的总读取或时间预算限制。

**移到回收站以后空间没变多？** 回收站里的文件仍然占用空间，需要时可以还原；清空回收站后才真正释放。首页清理结果会分开显示「已释放」和「在回收站」。

**AI 的判断一定对吗？** 不一定。所以 AI 不能扩大处理范围，也不能越过保护规则；没把握的、属于正在使用的程序的、最近还在改动的，都不会自动勾选。觉得不对，可以「问 AI」追问，或者直接不勾。

**软件卸载残留能找到多少？** 「应用 > 软件残留与登记」复用体检结果，也能单独检查应用数据和已记录的卸载位置。盘序从这个版本起把卸载记录保存在操作记录中，重启后仍能查；已重新安装或被其他软件认领的目录会排除。未匹配到安装登记且半年无活动的目录，从 10 MiB 起列为疑似残留，默认不勾选；旧版本数据从 20 MiB 起检查。没有记录的绿色软件、商店应用和用户自己保存的资料不能仅凭目录名称确认，所以不能保证找全，也不会把未匹配都当作垃圾。

**AI 和注册表检查做什么？** 首页的「陌生目录与残留」使用现有空间 AI 复核，残留行也可单独「问 AI」，提供本地发现的依据。软件登记检查只列出本地固定盘上安装目录与卸载程序均不存在的桌面程序，排除 MSI、运行库、驱动、相对命令及无法确认的位置。这里只读解释和给出修复建议，不修改注册表，不将登记条目数量换算成可释放空间。

## 当前状态

2.0.0 在 Windows 上通过单元测试、前端检查和脚本模型的演练端到端测试，并完成真实电脑的只读体检检查。统一窗口的拖动、缩放和跨页复用经过 Windows 原生窗口验证；打包版在其他电脑上的运行、UAC 提权、真实卸载等行为仍请参照 [Windows 验收清单](docs/ACCEPTANCE.md)。
