# 盘序：Win11 空间与后台助手

盘序围绕用户的整理目标组织 LLM、工具与界面。选择“清理 C 盘垃圾”“清理某个磁盘”“清理某个目录”或“查找重复文件”，助手按需调查、解释用途并提出方案。用户可以保留某项、补充要求、审阅和调整，程序把选择与核验结果带回任务。

当前 **0.9 本机便携版已通过本轮验收**，增加实时公开回复、独立整理偏好，以及更清楚的连接保存和测试反馈。默认主题跟随系统，也可手动选择浅色或深色。各版本的最终产物与确切验证范围见[发布记录](docs/RELEASES.md)。**当前只有模拟执行器**：处理与撤销只改变工具内部记录，实际释放空间始终为 0，不删除文件、不控制进程或服务、不卸载软件。界面顶部有测试保护提示。

## 启动

- 双击 [启动盘序.cmd](启动盘序.cmd)，或打开 `dist/PanXu` 双击 `PanXu.exe`。请保留整个文件夹及 `_internal`，不需要管理员权限。
- 源码：Python 3.11+，安装 `requirements.txt` 后执行 `python run.py`。原生窗口依赖 WebView2；缺少 pywebview 时可使用本地浏览器。
- 独立测试实例：`python run.py --headless --port 3558 --data-dir verification/ui-data`。服务仅监听回环地址，不接管用户浏览器配置。

## 使用流程

1. 首页选择目标和必要的位置即可开始，默认由模型决定先看哪里、要深入多少。后台、软件和文件列表也可以分析单项、勾选项或当前筛选的完整集合。
2. 助手先说明用途、原因与影响，再提出少量值得处理的建议。分析选择与处理选择分开，个人下载、创建和未知用途内容不会默认勾选。
3. 点击“保留这项”或补充要求会更新任务。明确选择并确认方案后，模拟后端逐项执行、核验并记录，再把结果反馈给助手。
4. 调查可以停止、继续和重新打开。任务记忆保存在本机；切换模型后依据已有目标、事实、选择和结果重新建立上下文。

助手可以提出选项问题，支持自由补充和暂不回答；选择偏好不表示同意处理。在用途建议里展开“自行处理”，可直接确认某项操作，程序先核验再把来源、选择和结果交回模型，当前仍为模拟。

首次使用默认跟随系统的亮色或暗色，可在设置中手动选择浅色或深色。已保存的手动选择不会被升级或系统配色变化覆盖，偏好也不随本地端口变化丢失。

“我的文件”按页读取，每页 50 项，搜索和换页保留选择。原始列表以分析为主，手动处理放在高级详情。模型不可用时仍可检查目录、盘点软件、核对重复，不伪装成 AI 分析。

列表图标在本机异步读取，不可用时使用类型图标，不阻塞清单。图标只是识别线索，不是发布者认证或安全证明，也不会作为图片发送给模型。

## 模型连接与开发记录

设置提供 18 项常见服务商/地域及自定义连接预设，包括 OpenAI、GLM、DeepSeek、Kimi、Qwen、Doubao、MiniMax、Claude、Gemini、Grok 与本地兼容服务。预设有官方来源和核对日期，可编辑模型 ID；账户权限、网络和额度仍以实际服务为准。

实现 Chat Completions、Responses、Anthropic Messages、Gemini 四种协议及其流式适配。“保存并测试”先保存有效设置和密钥，再用固定数据做非流式的两轮工具往返，不发送磁盘清单。测试未通过不撤销保存，也不清空当前填写内容；保存本身失败会单独说明。各厂商的工具选择和思考限制不同，详见 [v0.9 官方来源与探测政策](docs/PROVIDER_SOURCES_V090.md)。本机协议夹具不等于已使用真实云端密钥验证全部服务商或账户。

常用设置中的“整理偏好”对所有模型共用，可独立保存，不必重填连接或密钥。偏好用于后续分析；已有方案可继续调查后更新。保存偏好本身不会发起模型请求或自动重新分析。

任务与开发面板可边接收边阅读公开回复，文字平滑追赶已收到的内容；减少动画或隐藏窗口时直接追齐。断连保留已收到部分并标明未完成，最终修订以正确内容为准。“本轮回复接收完”不代表调查或清理完成。未闭合的工具参数不作为建议或动作展示，也不展示模型内部思考；自定义服务不支持流式时可在高级连接关闭。

按 **F12** 或在设置中点击“打开开发面板”，可在独立面板查看通信。面板每次启动默认关闭，打开不会自动开始采集；切换到文件或任务页时可继续观察。宽窗口在右侧展开，较窄窗口改为底部单列，面板独立滚动，主流程仍可操作。

采集和实时显示分别控制，可选择模型对话、技能内容或工具详情。请求和回复默认按角色与正文阅读，助手公开结论、问题和选项直接显示；系统提示、任务上下文、历史事实、技能、工具及用量按需展开，原始 JSON 放在更深一层。外层 `provider` 是程序内部的连接标签，不是 API 消息角色；实际请求或回复在记录的 `payload` 内。关闭工具详情仍能看见公开沟通内容，不能据此认为操作已执行或获批准。

只有面板打开、窗口可见且开启相应显示时，才连接实时公开回复并自动刷新记录；同一任务的本地 SSE 连接由任务页和面板共享。关闭面板会取消它的订阅，窗口隐藏会暂停连接，已经开启的采集继续按其开关运行。实时回复区独立更新，阅读展开历史时新记录仍暂存，切换分类不替换正在阅读的记录，也不重绘主表单。较长或未知格式的记录明确说明显示限制，不补造内容。

新档案的开发采集默认关闭。记录可包括实际请求、工具定义、公开响应和工具结果；密钥、鉴权头、内部思考及不透明协议续接不记入日志。记录有体积与条数上限，包含任务元数据，属于本机私有信息。

## 信息、扫描与任务记忆

内置 17 类经验指导，指导版本 1.1.0，涵盖缓存、临时文件、下载、备份、Windows 组件、休眠、分页、卸载迁移，以及回收站、云文件、虚拟盘、游戏开发、恢复材料、磁盘异常、后台和浏览器隐私等。模型按需发现并分页读取，带内容指纹和来源。指导不代表当前机器事实，不开放额外操作，具体范围见[技能说明](docs/SKILL_GUIDANCE.md)。

22 个任务工具中新增两项只读观察：`collect_system_configuration(memory_power)` 核对有限的内存提交、活动分页与配置、休眠能力等；`inspect_volume(scope_id)` 取得任务已有位置所在本地卷的容量、当前用户可用空间及回收站统计。未知或部分结果会注明，不能据此推断“没有配置”“可恢复”或“磁盘健康”；也不授权展开其他位置或修改系统。

程序提供本地元数据检查、目录统计、应用盘点、已知缓存经验、有预算的 SHA-256 重复校验。精确的字节比较和硬链接识别在本地完成；内容相同不自动意味着应删除。

任务保存目标、范围、反馈、选择、版本化方案、证据与动作收据。模型可查询工具说明和已保存事实。上下文压缩保留引用，跨模型交接重新组装事实，不复制原提供方的私有思考或协议签名。

大目录的调查、输出和语义分析有不同预算。部分读取、权限失败、停止、深度限制和仍需继续的范围必须如实报告；不能把一次采集当成全盘穷尽，也不能把模型轮次耗尽显示为任务完成。任务扫描索引的确切续接边界见 [Harness 说明](docs/TASK_FIRST_HARNESS.md)。

## 数据与边界

- 本地数据在程序旁的 `userdata`；可以用 `--data-dir` 指定位置。发布 ZIP 不包含用户数据、模型配置或测试数据库。
- 未配置模型不会向模型发送请求。配置后仅发送范围内的元数据，完整路径默认隐藏；不读取或上传文件正文、Cookie、密码或进程命令行。
- Windows 密钥使用当前用户 DPAPI 保存；非 Windows 只驻留内存。更换服务来源不能静默沿用旧密钥。
- 正规软件卸载、真实删除/回收站恢复、隐私清除、启动项和服务修改、跨盘迁移、休眠/页面文件/驱动调优均未实现。处理记录中的撤销只恢复内部模拟状态。
- 软件盘点主要覆盖传统桌面卸载项；后台/启动项是有限快照，不等于完整依赖和使用频率审计。目录根时间也不能证明全部后代没有变化。
- 新的系统与卷观察不包括 SMART、温度、固件、历史事件、完整电源策略或回收站恢复验证。相关指导可以帮助解释和继续调查，不能冒充已采集到这些证据。
