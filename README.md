# 盘序：Windows 11 磁盘清理助手

盘序帮你找出并清理 Windows 上占空间的东西：系统和应用的垃圾、陌生的大文件夹、你自己忘了的旧文件、大文件、重复文件、不用的程序，以及拖慢开机的启动项和服务。点一下「一键体检」就能得到一份清理方案：放心清理的项目已经勾好，其余的每一项都写明是什么、为什么、删了会怎样，也可以随时「问 AI」。常见情况由内置规则直接判断；规则不认识的，交给 AI 模型（默认 DeepSeek）给出建议。每一次修改都会记录下来。

1.0 是一次完全重写，取代了之前只做模拟、从未真正删除文件的 0.x 版本（旧代码保留在 git 历史中）。1.1 加入一键体检、我的文件、应用、AI 顾问和演练环境。

> **当前状态：** 1.1 在 Windows 11 上通过了 112 项单元测试和演练环境中的端到端测试（包括连接真实的 DeepSeek），界面在浏览器里接演练环境的真实后端检查过，真实窗口能正常打开。**还没有在真实系统上（非演练环境）按下面的「Windows 验收清单」走过一遍**，第一次在自己的电脑上使用前请先做这一步，或者先用 `--sandbox` 熟悉。

## 功能

| 页面 | 做什么 | 删除方式 |
|---|---|---|
| 首页 | 系统盘容量和「一键体检」：依次检查垃圾、系统盘空间、我的文件、重复文件，再让 AI 复核，生成分三组的清理方案（放心清理 / 建议你看看 / 仅供了解） | 垃圾规则直接删除，其余进回收站；确认框分别列出 |
| 我的文件 | 个人文件夹里：已装程序的安装包、没下完的文件、解压过的压缩包、同一文件的多个版本、很久没动的大文件、下载文件夹里的旧文件、空文件夹；可以让 AI 说说每个文件是什么 | 只移到回收站 |
| 应用 | 已安装的程序、大小、安装日期、最近运行时间；AI 说明哪些可以卸载 | 运行程序自己的卸载程序 |
| AI 顾问 | 任何页面、任何一行都能「问 AI」，可以追问 | — |
| 垃圾清理 | 30 多项内置规则：临时文件、更新缓存、错误报告、崩溃转储、浏览器和应用缓存、开发工具缓存、回收站、旧版 Windows、组件存储（DISM） | 直接删除（都是可以重建的缓存） |
| 空间分析 | 多线程扫描整个磁盘或文件夹，显示文件夹树和占用图，内置规则会标注已知位置的用途 | 默认移到回收站，可选直接删除 |
| AI 建议 | 只把规则不认识的大文件夹的摘要发给模型，得到「可清理 / 需要确认 / 建议保留」三类建议 | 默认移到回收站 |
| 大文件 | 列出扫描到的最大 5000 个文件，可按类型和修改时间筛选 | 默认移到回收站 |
| 重复文件 | 按大小、首尾片段、完整内容三步比对，跳过云端占位文件和硬链接，每组至少保留一份 | 只移到回收站 |
| 开机与服务 | 启用或禁用启动项（和任务管理器的「启动应用」是同一套开关），修改第三方服务的启动方式；AI 可以解释每一项是什么 | 不删除，可在操作记录中撤销 |
| 操作记录 | 每次清理、删除、修改都会记下时间、内容、释放的空间和失败的项目 | — |

## 安全设计

- **两种删除方式，分开处理。** 垃圾清理规则里的内容（缓存、临时文件）直接删除；其余所有用户选择或 AI 建议的项目默认移到回收站。放不进回收站的大文件，Windows 会先问你是否直接删除，不会悄悄删掉。
- **受保护的位置。** Windows 目录、Program Files 下的系统部分、ProgramData\Microsoft、各个用户文件夹的根目录、凭据和证书目录、应用商店的应用数据等，用户和 AI 都删不了。只要选中的文件夹里**包含**受保护的文件夹，也会被拒绝。路径会先解析成真实路径（8.3 短名、链接）再检查。你也可以在设置中添加自己的排除目录。
- **不穿越链接。** 扫描和删除都不会进入目录联接（junction）或符号链接；选中一个链接时只删除链接本身。OneDrive 的云端占位文件不计入占用、不会被读取（读取会触发下载）。
- **规则自带保险。** 只删除超过最短时间（例如临时文件 24 小时）的文件，按创建时间和修改时间中较新的那个算；正在使用的文件会跳过；相关程序（如 Chrome）还开着时整项跳过。如果 %TEMP% 被设置成不像临时文件夹的路径，这一项不会执行。
- **权限最小化。** 以普通权限启动。需要管理员权限的项目会标明，点「以管理员身份重启」才会弹出 UAC。
- **全部可追溯。** 中途停止也会记录已经完成的部分。

## AI 是怎么参与的

程序控制整个流程，模型只负责分类，不会自行调用工具或循环提问：

1. 内置规则先判断明显的情况：系统、程序、个人文件夹、已知缓存，这些都不发给模型。
2. 结构性的文件夹（C:\、用户文件夹、AppData\Local 等）自动展开，看它们的子文件夹。
3. 每个分支上第一个**规则不认识且足够大**（默认 500 MB 以上）的文件夹，生成一份摘要：路径（用户名替换成 %USERPROFILE%）、大小、文件数、修改时间、主要子文件夹、文件类型分布和最大的几个文件名。不上传文件内容。
4. 模型对每个文件夹回答：可以清理、建议保留、需要你确认，或者「内容混合，请看这几个子文件夹」。只有最后一种才会在下一轮继续细看，而且总请求数有上限（默认 8 次，每次最多 12 个文件夹）。
5. 结果缓存 30 天，文件夹大小变化不大时重新分析不消耗额度。

开始分析前会列出将要发送的全部文件夹。支持 DeepSeek、Kimi、智谱 GLM、通义千问、硅基流动、OpenAI、Anthropic、本地 Ollama 以及任何 OpenAI 兼容接口。API Key 用 Windows 账户加密（DPAPI）保存在本机；装过 0.x 的电脑会自动导入 0.x 保存的 Key。

1.1 中 AI 还参与这些地方，同样由程序决定发什么、结果怎么用：

- **一键体检**：空间分析之外，把「我的文件」的文件名（不含内容）和已启用的启动项交给模型复核。AI 的判断只决定一项放进哪一组、附上什么说明；只有把握很大、位于应用数据目录、而且不属于仍在使用的程序的文件夹（通常是卸载残留）会默认勾选，个人文件永远不会。
- **建议清理度**：方案和「我的文件」里每一项都有一个 0–100 的分数和评分依据（规则、AI 的把握、盘序的判断），一眼就能看出为什么这样建议、为什么勾或没勾。分数只用来说明和排序，是否自动勾选仍然只由上面的固定规则决定。
- **文件夹摘要的线索**：程序先把 AppData 文件夹和「已安装的应用」做匹配，告诉模型「找不到对应的程序」「旁边有更新的版本」「三年没改过」，帮它识别卸载残留和旧版本。只发送匹配结果，不发送程序列表。
- **我的文件**：文档开头的内容只有在设置里允许、并且这一次确认框里再次勾选时才会发送，确认框会列出要读的文档。
- **问 AI**：上下文（匿名化的路径、大小、盘序已知的说明、保护原因）由程序生成；模型被要求先给结论、不确定就直说、不能声称做过任何操作。第一次提问的回答缓存 30 天。
- DeepSeek 的思考模式在判断类请求中总是关闭；设置里的「深度思考」只影响问 AI。

## 运行

**直接运行（打包后）：** 双击 `dist\PanXu\PanXu.exe`，或双击项目根目录的 `启动盘序.cmd`。需要 Windows 10/11 x64 和 WebView2 运行时（Windows 11 自带）。

**从源码运行：**

```powershell
python -m pip install -r requirements.txt
python run.py            # 加 --debug 可以打开 WebView 开发者工具
```

设置、操作记录、AI 缓存和日志保存在 `%LOCALAPPDATA%\PanXu`。

**演练环境：** `python run.py --sandbox`（或 `PanXu.exe --sandbox`）会在 `%LOCALAPPDATA%\PanXu\sandbox` 生成一台「用了几年的电脑」——C 盘和 D 盘、各种缓存、下载的安装包、论文的好几个版本、假的注册表和服务——所有删除、禁用、卸载都只发生在这个文件夹里，窗口顶部有提示条，可以查看演练回收站（能还原）或重建演练环境。大文件是稀疏文件，几十 GB 的逻辑大小只占几 MB 磁盘（需要 NTFS）。第一次进入时会复制你已配置的模型和 Key，所以 AI 功能可以直接试。也可以指定文件夹：`--sandbox D:\panxu-demo`。

**打包：**

```powershell
python -m pip install -r requirements.txt pyinstaller
.\build.ps1
```

会先跑单元测试，然后生成 `dist\PanXu\PanXu.exe` 和对应的 zip。已有的 `dist\PanXu` 会被改名保留，不会被覆盖。

## Windows 验收清单

以下行为只能在真实的 Windows 上确认。建议先在不重要的文件夹上试：

0. 先运行 `python run.py --sandbox`：标题栏显示「（演练环境）」，顶部有提示条。做一次一键体检、执行全部方案、在演练回收站里还原一项、模拟卸载一个程序、问一次 AI，确认真实的用户文件夹和回收站都没有变化。
1. 普通权限启动：窗口能打开，首页显示系统盘容量，其他磁盘列在下面。
2. 再次双击启动：只把已有窗口切到前台。
3. 垃圾清理：勾选「用户临时文件」清理，释放的空间和操作记录一致；24 小时内的文件仍在。Chrome 开着时，Chrome 一项显示「请先关闭」。
4. 以管理员身份重启：弹出 UAC，新窗口左下角显示「管理员模式」，Windows 临时文件等项目可以扫描。
5. 空间分析：扫描 C 盘能完成（通常 1 到 3 分钟），占用图可以点进文件夹，WinSxS、hiberfil.sys 等有说明。
6. 在一个测试文件夹里新建文件，在空间分析中选中它们「移到回收站」，确认回收站里能找到并还原。再试一次「直接删除」。
7. 尝试删除 `C:\Users\你的名字\AppData\Local` 或其中的 `Microsoft` 文件夹：应当被拒绝。
8. 设置里填入 DeepSeek 的 API Key，点「测试连接」成功；在空间分析中运行 AI 分析，确认发送前列出的路径已隐藏用户名。
9. 重复文件：复制两份同样的文件，能找到；勾选两份时提示至少保留一份。
10. 开机与服务：禁用一个启动项后，任务管理器的「启动应用」里也显示已禁用；在操作记录里撤销后恢复。
11. 一键体检：完成后「放心清理」只勾了垃圾规则（和把握很大的应用数据文件夹），个人文件都没有勾；执行前的确认框分别列出永久删除和进回收站的项目；执行后操作记录完整。
12. 我的文件：能找到下载文件夹里已装程序的安装包；「让 AI 看看这些文件」的确认框列出要发送的文件，没有在设置里允许时不能勾选发送内容。
13. 应用：列表和「设置 > 应用 > 已安装的应用」一致（不含系统组件和更新）；以管理员身份运行时有「最近运行」；「卸载…」打开的是程序自己的卸载程序。
14. 打包版：运行 `build.ps1`，在另一台没有装 Python 的电脑上运行 `PanXu.exe`。
