# 盘序：AI 磁盘清理助手

盘序围绕用户的整理目标组织 LLM、工具与界面。选择“清理 C 盘垃圾”“清理某个磁盘”或“清理某个目录”，助手按需调查、解释用途并提出方案。用户可以保留某项、补充要求、审阅和调整，程序把选择与核验结果带回任务。“查找重复文件”另有独立的本地工具，无需连接模型。

当前 **0.14.0 已完成本机验收**。本轮将后台、服务、启动项及软件任务接入建议/全部项目与勾选处理流程，并直接展示用途、建议、原因和影响。确切验证范围见[发布记录](docs/RELEASES.md)。**当前只有模拟执行器**：处理与撤销只改变工具内部记录，实际释放空间始终为0，不删除文件、不控制进程或服务、不卸载软件。操作按钮使用具体动作名，模式统一由全局提示说明；名称变化不代表新增真实执行能力。独立重复结果目前只读。

## 启动

- 双击 [启动盘序.cmd](启动盘序.cmd)，或打开 `dist/PanXu` 双击 `PanXu.exe`。请保留整个文件夹及 `_internal`，不需要管理员权限。
- 源码：Python 3.11+，安装 `requirements.txt` 后执行 `python run.py`。原生窗口依赖 WebView2；缺少 pywebview 时可使用本地浏览器。
- 独立测试实例：`python run.py --headless --port 3558 --data-dir verification/ui-data`。服务仅监听回环地址，不接管用户浏览器配置。

## 使用流程

1. 首页选择目标和必要的位置即可开始，默认由模型决定先看哪里、要深入多少。后台、软件和文件列表也可以分析单项、勾选项或当前筛选的完整集合。
2. 助手给出简短结论和1–5分的清理倾向，每项用途、建议、原因和影响直接分区阅读，来源和技术细节按需查看。分析对象与最终处理对象分别选择；高分初选只是可修改的草案。
3. 在本次任务的清单中核对勾选。目录可整体选择并保留子项例外；后台项目分别选择具体对象和动作。确认前按删除、关闭开机启动、停止服务、结束进程或卸载等动作核对数量，后端再逐项核验、记录结果，并可暂停、继续或取消尚未处理的部分。
4. 调查可以停止、继续和重新打开。任务记忆保存在本机；切换模型后依据已有目标、事实、选择和结果重新建立上下文。

助手可以提出选项问题，支持自由补充和暂不回答；选择偏好不表示同意处理。用户也可明确选择具体动作，由程序核验并建立待确认清单，无需模型再发一次操作命令；来源、选择和结果会保留到任务中，当前仍只作用于模拟记录。

首次使用默认跟随系统的亮色或暗色，可在设置中手动选择浅色或深色。已保存的手动选择不会被升级或系统配色变化覆盖，偏好也不随本地端口变化丢失。

“我的文件”每页按需读取50项，建议视图突出直接评估；任务清单也能查看继承、跳过和未评分内容。“目录结构（已扫描）”浏览已保存的观察，进入目录不会悄悄扫描。未扫描部分不代表为空。分类勾选面向本次任务的完整筛选范围，每批最多500个去重后的选择目标；超出时显示尚未纳入的数量，需要明确分批，不能把本页或首批称为全部。模型不可用时仍可检查目录、盘点软件、核对重复，不伪装成AI分析。

后台任务提供“建议清单”和“全部项目”。全部只指本次任务的已知、可处理范围，包含尚未分析内容，不代表全机盘点；普通库存中的勾选用于分析，任务结果中的勾选用于处理。相同程序的不同进程、服务和启动项仍是不同对象，不因名称或程序路径相同合并。停止服务仅针对当前运行，不改变服务启动方式；关闭开机启动不等于结束当前进程，结束进程也不等于卸载软件。

没有模型判断的项目只给简短的尚未分析或本机类型说明，不补造用途建议和评分。有判断的条目直接显示完整用途、建议、原因和影响；已分析但未评分、明确跳过、暂不建议及失效旧建议分别显示。尚无可用具体动作时会注明操作待确认，不猜成删除。底色和标签帮助区分用途、建议、依据与影响，颜色本身不表示安全或已执行。

列表图标在本机异步读取，不可用时使用类型图标，不阻塞清单。图标只是识别线索，不是发布者认证或安全证明，也不会作为图片发送给模型。

## 独立查找重复文件

从首页进入“查找重复文件”，选择要比较的1–8个本地目录即可开始，不需要填写模型连接，也不发送文件内容给模型。程序先按文件大小排除不可能相同的文件，再读取同大小候选的内容计算SHA-256。它不再追加第二轮逐字节比较，也不把文件名相同当作内容相同。Windows通常不会为每个普通文件保留一个随内容更新、可直接通用读取的SHA-256，因此计算需要实际读取候选文件；目录大或同大小文件多时会产生磁盘读取。

结果按内容哈希分组，硬链接另行说明：多个路径共享同一文件实体，不是多份独立占用。SHA-256相同提供很强的内容一致证据，但不是数学意义的100%证明，也不表示副本无用、可直接删除或能释放所列大小。初版结果仅供查看，不直接删除、不创建评分，也不混进已有文件清单。

受保护、凭据、项目、链接和可能需要下载的云端占位文件会跳过；读取前后还会检查文件身份和变化。权限失败、文件变化、取消或达到条目、深度、读取量等预算时，会显示未完整检查与遗漏数量；所有指定目录都不可访问时显示检查失败，不能当作没有重复。已显示结果不代表整个磁盘没有其他重复项。需要判断用途、保留位置与路径引用时，仍可另行发起LLM整理任务；重复识别本身是程序化事实工具，不将产品主线改为固定清理规则。

实现 Chat Completions、Responses、Anthropic Messages、Gemini 四种协议及其流式适配。“保存并测试”先保存有效设置和密钥，再用固定数据做非流式的两轮工具往返，不发送磁盘清单。测试未通过不撤销保存，也不清空当前填写内容；保存本身失败会单独说明。各厂商的工具选择和思考限制不同，详见 [v0.9 官方来源与探测政策](docs/PROVIDER_SOURCES_V090.md)。本机协议夹具不等于已使用真实云端密钥验证全部服务商或账户。

常用设置中的“整理偏好”对所有模型共用，可独立保存，不必重填连接或密钥。偏好用于后续分析；已有方案可继续调查后更新。保存偏好本身不会发起模型请求或自动重新分析。

任务与开发面板可边接收边阅读公开回复，文字平滑追赶已收到的内容；减少动画或隐藏窗口时直接追齐。断连保留已收到部分并标明未完成，最终修订以正确内容为准。任务另外保存最近一条被接受的公开回复，重新打开或重启后仍可阅读；超过保存上限会明确标注，未完成的实时片段不冒充已保存结论。“本轮回复接收完”不代表调查或清理完成。未闭合的工具参数不作为建议或动作展示，也不展示模型内部思考；自定义服务不支持流式时可在高级连接关闭。

公开回复旁的“最近动态”保留接收、工具请求与连接状态，默认看最近3条；快速变化时在有限区域暂留并可回看，错误立即提示。约4秒只是有界的显示保留窗口，不让后台等待，也不保证每种状态都完整显示4秒。当前窗口会话最多保留8个任务、每任务32条，较早条目会省略；它不是持久调查或执行账本，不保存思考与工具参数。完整调查记录、已保存公开回复和逐项执行结果仍分别查看。

按 **F12** 或在设置中点击“打开开发面板”，可在独立面板查看通信。面板每次启动默认关闭，打开不会自动开始采集；切换到文件或任务页时可继续观察。宽窗口在右侧展开，较窄窗口改为底部单列，面板独立滚动，主流程仍可操作。

采集和实时显示分别控制，可选择模型对话、技能内容或工具详情。请求和回复默认按角色与正文阅读，助手公开结论、问题和选项直接显示；系统提示、任务上下文、历史事实、技能、工具及用量按需展开，原始 JSON 放在更深一层。外层 `provider` 是程序内部的连接标签，不是 API 消息角色；实际请求或回复在记录的 `payload` 内。关闭工具详情仍能看见公开沟通内容，不能据此认为操作已执行或获批准。

只有面板打开、窗口可见且开启相应显示时，才连接实时公开回复并自动刷新记录；同一任务的本地 SSE 连接由任务页和面板共享。关闭面板会取消它的订阅，窗口隐藏会暂停连接，已经开启的采集继续按其开关运行。实时回复区独立更新，阅读展开历史时新记录仍暂存，切换分类不替换正在阅读的记录，也不重绘主表单。较长或未知格式的记录明确说明显示限制，不补造内容。

新档案的开发采集默认关闭。记录可包括实际请求、工具定义、公开响应和工具结果；密钥、鉴权头、内部思考及不透明协议续接不记入日志。记录有体积与条数上限，包含任务元数据，属于本机私有信息。

## 建议来源

建议详情可按需展开“建议来源”，查看服务商、实际请求配置的模型ID及生成时间（本机时区）。来源由宿主从对应请求快照记录，不由模型自报；切换连接或重开程序不会改写旧建议的署名。重新分析保存了新建议后，来源与时间一起替换；用途建议和后来生成的操作方案分开保留来源。

旧记录没有来源时显示未记录，本机规则与用户发起分别注明。来源仅记录生成过程，不代表内容已验证正确或操作已执行。失败或未形成有效新建议不能刷新旧时间。

## 更少输入与分层建议

发送给模型的任务上下文和工具结果使用紧凑的缩进文本，减少大段JSON括号与重复字段；未知、0、false、范围、ID和分页引用仍分别保留。原生API外层、工具定义及工具调用参数继续使用各协议所需的类型化格式，模型的公开说明不要求写成JSON。用户与助手的普通正文不因压缩而改写。

任务提示按职责保留，说明目录和初始样本不再重复铺陈；22项工具定义继续可用，技能正文按需读取。初始样本外的对象与完整事实仍在本机保存，可以按ID查询，不通过丢失事实来压缩输入。输入收益以同一隔离样本的模型可见文本和schema度量，HTTP传输字节与估算值不当作提供方的实际token用量。

主清单优先短结论、评分及首条重要“留意”，完整重点、其他提醒与检查范围放进“分析详情”，给文件清单留出主要空间。该页保留公开回复、长说明、全部模块与来源；“调查过程”查看范围、工作量、事件和按需读取的指导/事实；“调整要求”保留输入草稿。必要的用途、原因、影响及来源仍可到达，左上返回不清空当前任务或勾选。减少折叠不等于删除信息或把重要影响藏起来；评分帮助浏览和筛选，具体操作、个人决定与模拟确认独立表达。

主清单只预览最多160字，分析详情保留完整结论。建议简短表达是写作指导，不会因为同时提供重点模块，就拒收仍在工具允许长度内的有效结论。

每轮调查仍最多6次模型请求、12次工具调用，通常前4次调查，后2次留给评分与结论；必要时更早收束。模型每次提交最多6项评分或操作建议。输出碰到本地上限或服务商明确报告token截断时，最多在现有轮次内额外进行一次基于已保存事实的收束，不重复采集或执行未接收完整的工具调用，也不无限重试。普通断流不会套用这种恢复。未形成完整结论会说明已有结果保留、范围尚未完成；这类提示不直接等同于网络或密钥故障。

## 清理倾向与目录继承

5分强烈倾向清理，4分倾向清理，3分中立，2分倾向保留，1分强烈倾向保留。五格刻度表示顺序，不是安全概率或已获删除许可。未评分、明确跳过、暂不建议与3分分别显示；旧记录不补造分数。

模型可以只评估有意义的目录和文件。只有明确标记“涵盖子项”的目录内容建议才向下继承；更具体的判断、明确跳过、暂不建议、旧未评分或失效记录阻断上层建议继续传播。继承项会注明来自哪个目录与原建议的模型时间，不能冒充逐文件分析。软件卸载建议不会给安装目录中的DLL自动赋予删除资格。

初次展示本轮建议时，可自动勾选具备操作资格的5分项，默认也包含4分；设置中可关闭自动勾选4分。合格的继承项也可纳入，但不能越过更具体的低分、跳过、未评分或保留例外；其他任务的旧建议不会混进本轮自动初选。分批时先纳入直接评估，再纳入继承项。刷新不会反复覆盖用户已经调整的勾选。

1–5分、跳过、暂不建议和未评分可以分别批量选择或取消。低分与未知内容仍允许用户明确手选；分数不替用户授权。选择目录后取消子项，程序会将目录拆成可操作的具体目标，保留例外；在已取消的子目录中重新选择单个文件也有效。未扫描、范围外、受保护或不支持操作的内容不会被父目录一并吞入。用户最后的明确勾选可以覆盖本任务先前的临时“保留/稍后”选择，不能覆盖全局保护或身份核对。

确认前核对最终清单、例外、覆盖缺口及当前批次数量。模拟执行中的暂停和取消在项目之间生效，已提交的记录保留；取消不等于撤销。整批结束后可查看逐项结果，未处理部分不能显示成已清理。个人文件是否处理仍以用户最终选择为准。

建议分数回答“有多推荐清理”，操作名称回答“要做什么”，“由你选择”回答“谁来决定”。操作名称和个人确认不能用分数替代；中立条目可用“3/5 · 由你决定”减少重复标签。

创建、修改时间只说明当前条目的时间记录，目录时间不是所有后代的最后修改时间，访问时间也不是可靠的最近使用记录。指南还综合用户意愿、用途、唯一性、源码与备份价值、可重建性、保留副本、依赖及证据缺口；不会用固定年龄公式直接打分。

## 信息、扫描与任务记忆

内置 18 类经验指导，指导版本 1.2.0，涵盖缓存、临时文件、下载、备份、Windows 组件、休眠、分页、卸载迁移，以及回收站、云文件、虚拟盘、游戏开发、恢复材料、磁盘异常、后台和浏览器隐私等。模型按需发现并分页读取，带内容指纹和来源。指导不代表当前机器事实，不开放额外操作，具体范围见[技能说明](docs/SKILL_GUIDANCE.md)。

22 个任务工具中新增两项只读观察：`collect_system_configuration(memory_power)` 核对有限的内存提交、活动分页与配置、休眠能力等；`inspect_volume(scope_id)` 取得任务已有位置所在本地卷的容量、当前用户可用空间及回收站统计。未知或部分结果会注明，不能据此推断“没有配置”“可恢复”或“磁盘健康”；也不授权展开其他位置或修改系统。

程序提供本地元数据检查、目录统计、应用盘点、已知缓存经验，以及大小分组后的有预算SHA-256重复识别。哈希计算与硬链接识别在本地完成；内容相同不自动意味着应删除。

任务保存目标、范围、反馈、选择、版本化方案、证据与动作收据。模型可查询工具说明和已保存事实。上下文压缩保留引用，跨模型交接重新组装事实，不复制原提供方的私有思考或协议签名。

大目录的调查、输出和语义分析有不同预算。部分读取、权限失败、停止、深度限制和仍需继续的范围必须如实报告；不能把一次采集当成全盘穷尽，也不能把模型轮次耗尽显示为任务完成。任务扫描索引的确切续接边界见 [Harness 说明](docs/TASK_FIRST_HARNESS.md)。

## 数据与边界

- 本地数据在程序旁的 `userdata`；可以用 `--data-dir` 指定位置。发布 ZIP 不包含用户数据、模型配置或测试数据库。
- 未配置模型不会向模型发送请求。配置后仅发送范围内的元数据，完整路径默认隐藏；普通模型调查不读取或上传文件正文、Cookie、密码或进程命令行。重复查找在本地读取候选内容计算哈希，内容不发送给模型。
- Windows 密钥使用当前用户 DPAPI 保存；非 Windows 只驻留内存。更换服务来源不能静默沿用旧密钥。
- 正规软件卸载、真实删除/回收站恢复、隐私清除、启动项和服务修改、跨盘迁移、休眠/页面文件/驱动调优均未实现。处理记录中的撤销只恢复内部模拟状态。
- 软件盘点主要覆盖传统桌面卸载项；后台/启动项是有限快照，不等于完整依赖和使用频率审计。目录根时间也不能证明全部后代没有变化。
- 新的系统与卷观察不包括 SMART、温度、固件、历史事件、完整电源策略或回收站恢复验证。相关指导可以帮助解释和继续调查，不能冒充已采集到这些证据。
