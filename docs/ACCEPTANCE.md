# Windows 验收清单

以下行为只能在真实的 Windows 上确认，自动测试和演练环境替代不了。建议先在不重要的文件夹上试，每一项都可以对照「操作记录」。

0. **演练环境：** 运行 `PanXu.exe --sandbox`（或 `python run.py --sandbox`）。导航底部显示「演练环境」，顶部有提示条。做一次一键体检、执行勾选的方案、在演练回收站里还原一项、单独模拟卸载一个程序、问一次 AI，确认真实的用户文件夹和回收站都没有变化。
1. **启动与窗口：** 普通权限启动，窗口能打开，首页显示系统盘容量与逐盘勾选。再次双击只把已有窗口切到前台。统一顶栏可拖动、双击最大化、最小化和关闭；边缘可缩放，连续最大化/还原后尺寸稳定，深浅主题与标题栏一致。
2. **垃圾清理：** 勾选「用户临时文件」清理，释放的空间和操作记录一致，24 小时内的文件仍在。Chrome 开着时，Chrome 一项显示「请先关闭」，关掉后自动解锁。
3. **管理员：** 「以管理员身份重启」弹出 UAC，新窗口左下角显示「管理员模式」，Windows 临时文件等项目可以扫描。
4. **空间分析：** 扫描 C 盘能完成（通常 1 到 3 分钟），占用图单击看详情、双击进入，WinSxS、hiberfil.sys 等有说明。
5. **回收站：** 在测试文件夹里新建文件，在空间分析中「移到回收站」，回收站里能找到并还原；再试一次「直接删除」。删除时在窗口别处点一下，进度对话框不消失。
6. **回收站放不下的：** 删除一个比回收站容量还大的测试文件夹，Windows 询问是否直接删除时选「是」：完成对话框写「完成，部分已直接删除」，操作记录标着「已直接删除」，不说「已移到回收站」。
7. **保护：** 尝试删除 `C:\Users\你的名字\AppData\Local` 或其中的 `Microsoft` 文件夹，应当被拒绝。
8. **AI：** 设置里填入 API Key，「测试连接」成功；在空间分析中运行 AI 分析，发送前列出的路径已隐藏用户名。开机与服务里，你正在用的应用（例如开着的聊天客户端）的服务不会被建议禁用。
9. **重复文件：** 复制两份同样的文件，能找到；只勾一份时正常移到回收站；两份都勾时有「一份都不保留」的提示，确认后两份都进回收站。代码工程里的副本标出所在的工程。
10. **开机与服务：** 禁用一个启动项后，任务管理器的「启动应用」里也显示已禁用；在操作记录里撤销后恢复。
11. **一键体检：** 「放心清理」里每一项都达到勾选门槛（默认 5 分），个人文件都没有勾。点「≥ 8 分」只剩 8 分以上的，点「全不选」全部取消。执行前的确认框分别列出永久删除和进回收站的项目；执行后顶部的结果卡片和可用空间的「+X」与实际相符，处理过的项目收进「已处理」。在「垃圾清理」里取消勾选一项，回到首页它也是没勾的。
12. **中途关闭：** 清理进行中关闭窗口，先询问；确认后在当前文件处理完后停下，操作记录里有这次清理。用任务管理器结束 PanXu.exe 后重新打开，那条记录标着「没有完成」。
13. **我的文件：** 能找到下载文件夹里已装程序的安装包；「让 AI 看看这些文件」的确认框列出要发送的文件，设置里没有允许时不能勾选发送文档内容。
14. **应用：** 列表和「设置 > 应用 > 已安装的应用」一致（不含系统组件和更新），大部分程序显示自己的图标；以管理员身份运行时有「最近运行」；「卸载…」打开的是程序自己的卸载程序，卸载完成后列表自己更新并提示「查找残留」。
15. **打包版：** 在另一台没有装 Python 的电脑上解压 `PanXu-<版本>-win-x64.zip`，运行 `PanXu.exe`，重复 1、2、5 三项。
16. **结果复用与排序：** 体检进行中进入垃圾清理等工具，再点扫描会显示进度与复用提示；阶段完成后结果自动更新。体检结束后，应用和第三方服务的 AI 结论在工具页可见，关闭对应选项时首页明确标为未检查。点击列表表头或排序栏可切换正反顺序，空值在最后。
17. **应用与服务方案：** 应用卸载和服务修改不自动勾选。应用只能逐个运行自己的卸载程序；服务改为手动不会停止正在运行的服务，操作记录保存原启动方式并可撤销。在工具页操作后首页方案同步状态。
18. **实际占用与演练目录：** 对稀疏/压缩测试文件分别核对标称大小与实际占用；真实模式按占用计数。保留在其他目录中的演练环境在空间页有说明，个人文件与重复文件不进入其中。
