# 按需经验指导与用户操作

0.6把“经验”“本机事实”“用户意愿”和“实际能力”分开。模型可以主动判断何时值得讨论迁移、卸载或系统空间；程序不因匹配某目录就强制套用建议。

## 指导如何进入任务

`list_skills`按用途发现内置指导，`read_skill`分页读取。每份指导带版本、完整内容指纹、核对日期与来源，任务保存已读版本；正文通过工具结果交给模型，开发记录可查看当时实际发送的内容。重新打开或切换模型时可根据版本重新读取。

内置9类：应用/开发工具缓存、临时文件、下载/安装包、备份/系统升级、Windows组件、休眠/快速启动、分页/虚拟内存、正规卸载/残留、资料/已知文件夹迁移。来源优先使用Microsoft、Astral、PyPA和npm官方资料，具体链接在注册表元数据与界面中查看。

历史清理经验是调查方法，不代表当前机器状态。关闭休眠会改变恢复会话的能力，分页大小与工作负载/转储需求有关，系统回退材料也有恢复价值。这些指导不会把相关内容变成普通垃圾，不会凭指南获得尚未实现的配置或维护工具。

固定注册表位于`diskpilot/knowledge.py`，正文位于`skills/`。这里只加载固定白名单的程序资源，不读取任意路径或网址。单份资源最多32KiB，工具输出按完整序列化UTF-8字节做保守预算；这不是提供方的实际token计费数据。较长正文分页，游标绑定内容指纹。新增或修改指导必须核对来源、适用条件、版本、资源测试和打包散列；当前尚不提供用户编辑技能界面。

## 用户与模型如何选择

模型的`ask_user`一次提出一个问题和2到5个选项。用户可以选择、自由补充或暂不回答。问题版本绑定回答，过期问题不能重放；回答只是偏好，不产生处理批准。

用户也可以展开用途建议中的“自行处理”。程序显示对象、位置和影响，用户点击明确的处理按钮后，直接建立目标绑定方案并通过同一批准/核验运行时，不必等待模型再次调用`propose_plan`。任务保存`user_direct`来源、具体选择、计划版本与逐项结果，模型下一次请求会收到这些信息。失败或暂时没有模型连接时，结果仍先保存在本机。

独立高级手动处理的历史，只将与当前任务已知对象相交的记录提供给模型，不静默扩大外发范围。模拟结果实际释放量始终为0；真实删除、卸载、系统调优和恢复仍须独立开发。

## 调试与普通界面

普通界面只展示结论、当前问题或下一步。开发模式中，采集默认关闭，实时显示单独控制，可分别查看模型公开对话、技能内容和工具详情。隐藏工具细节仍保留原始公开结论/问题；不把显示摘要推断成操作成功。密钥、内部推理和协议私有续接不记录。

实时读取限于面板可见时，展开阅读期间暂存新记录；刷新不重建模型设置表单。默认暗色、浅色/系统选择和开发显示偏好保存在本机数据中，跨随机端口继续生效。
