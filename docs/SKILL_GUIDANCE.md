# 按需经验指导与用户操作

v0.8 继续把“经验”“本机事实”“用户意愿”和“实际能力”分开。模型可以主动判断何时值得讨论迁移、卸载或系统空间；程序不因匹配某目录就强制套用建议。当前有 17 类指导、22 项任务工具，依然只有模拟执行器。确切覆盖与缺口见 [v0.8 指导覆盖审查](GUIDANCE_COVERAGE_V080.md)。

## 指导如何进入任务

`list_skills`按用途发现内置指导，`read_skill`分页读取。每份指导带版本、完整内容指纹、核对日期与来源，任务保存已读版本；正文通过工具结果交给模型，开发记录可查看当时实际发送的内容。重新打开或切换模型时可根据版本重新读取。

内置指导为 1.2.0 版，来源核对日期为 2026-11-02。18 类包括：应用/开发工具缓存、临时文件、下载/安装包、备份/系统升级、Windows 组件、休眠/快速启动、分页/虚拟内存、正规卸载/残留、资料/已知文件夹迁移，以及存储感知/回收站、云文件、WSL/Docker 虚拟盘、游戏/开发项目、系统保护/恢复、磁盘健康、开机/后台、浏览器隐私/本地模型，以及综合评分/时间证据与目录继承。来源限于已核对的微软和相应厂商官方资料；注册表中保存逐项链接、版本与核对日期，不把来源网页当本机状态。

历史清理经验是调查方法，不代表当前机器状态。关闭休眠会改变恢复会话的能力，分页大小与工作负载/转储需求有关，系统回退材料也有恢复价值。这些指导不会把相关内容变成普通垃圾，不会凭指南获得尚未实现的配置或维护工具。

固定注册表位于`diskpilot/knowledge.py`，正文位于`skills/`。这里只加载固定白名单的程序资源，不读取任意路径或网址。单份资源最多32KiB，工具输出按完整序列化UTF-8字节做保守预算；这不是提供方的实际token计费数据。较长正文分页，游标绑定内容指纹。新增或修改指导必须核对来源、适用条件、版本、资源测试和打包散列；当前尚不提供用户编辑技能界面。

目录查询默认最多 5 项、程序预算 3000；正文预算 4000，必要时通过游标继续。17 类不会自动全部拼进系统提示。任务恢复只提供已读 ID、版本和指纹；更换模型后，若需要正文，应重新调用 `read_skill`，不能声称模型天然记得上次读到的完整内容。

## 用事实核对指导

`collect_system_configuration(section=memory_power)` 使用固定原生 API 与 7 个固定只读注册表值，取得当前内存提交、当前启动以来的峰值、活动分页文件及请求配置、休眠能力/文件存在性和部分转储/快速启动配置。配置不是实际生效的全部状态；未读到临时分页标志不等于没有临时分页，快照也不能计算长期负载的“最佳大小”。

`inspect_volume(scope_id)` 只查询任务已有位置所在的一个本地卷，取得容量、当前用户可用空间和回收站统计，不列回收站文件。文件单选任务可从 `volume_scopes` 或 `list_scopes(purpose=volume)` 取得统计引用；该引用不会开放父目录遍历、其他盘或新动作对象。

两项结果均带来源、开始/完成时间、预算、`partial`、警告和空的 `actions`。不支持、权限失败、缺少值或格式未知分别保留；统计成功不是恢复保证，也不是硬盘健康证明。原生调用数量与输出有界，但单次系统调用不能中途打断。

工具观察保存为 `tool_observation` 历史事实；读过的指南保存为 `skill_guidance`，标明版本和内容指纹。两者都可通过 `read_facts` 核对，但指导不是当前机器的事实，旧观察也不是执行前的当前快照。默认关闭外发路径时，分页配置仍以卷、有限系统文件名和初始/最大 MB 提供有效数值；完整活动文件路径须遵循现有隐私设置。

## 用户与模型如何选择

模型的`ask_user`一次提出一个问题和2到5个选项。用户可以选择、自由补充或暂不回答。问题版本绑定回答，过期问题不能重放；回答只是偏好，不产生处理批准。

用户也可以展开用途建议中的“自行处理”。程序显示对象、位置和影响，用户点击明确的处理按钮后，直接建立目标绑定方案并通过同一批准/核验运行时，不必等待模型再次调用`propose_plan`。任务保存`user_direct`来源、具体选择、计划版本与逐项结果，模型下一次请求会收到这些信息。失败或暂时没有模型连接时，结果仍先保存在本机。

独立高级手动处理的历史，只将与当前任务已知对象相交的记录提供给模型，不静默扩大外发范围。模拟结果实际释放量始终为0；真实删除、卸载、系统调优和恢复仍须独立开发。

## 调试与普通界面

普通界面只展示结论、当前问题或下一步。开发模式中，采集默认关闭，实时显示单独控制，可分别查看模型公开对话、技能内容和工具详情。隐藏工具细节仍保留原始公开结论/问题；不把显示摘要推断成操作成功。密钥、内部推理和协议私有续接不记录。

实时读取限于面板可见时，展开阅读期间暂存新记录；刷新不重建模型设置表单。默认跟随系统，可选浅色/深色，主题和开发显示偏好保存在本机数据中，跨随机端口继续生效。开发采集与显示过滤相互独立，不因切换可见类别就开始采集。
