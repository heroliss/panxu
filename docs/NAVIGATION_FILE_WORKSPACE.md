## 导航分工

左侧分为“首页”“整理进度”“文件清理”“已删除文件”“后台与软件”“清理工具”“操作记录”“设置”。“文件清理”同时提供已有建议和全部文件，后者从盘符逐层读取，仍不表示已分析全机。“清理工具”及额外建议详见[统一能力方案](CLEANUP_TOOLBOX_AND_EXTENSIONS.md)；0.19的专项往返继续复用。

- **首页**：少量目标快捷入口，不维护第二套扫描或选择实现。清理C盘、某磁盘、某目录将目标和授权位置交给同一文件工作区，并关联调查任务；纯查看位置不自动分析。后台/软件及独立查重仍进入适合其对象和事实工具的工作区。
- **整理进度**：会话、问题、短结论、覆盖缺口与恢复入口；以task_id/范围/筛选打开对应列表。普通分析直接在列表中继续，列表上方显示实时进度和暂停/继续；不复制完整文件管理器或独立勾选状态。
- **文件清理**：位置、文件和目录的唯一浏览与处理工作区。顶层显示磁盘，支持路径与面包屑、当前层浏览、评分筛选及按需分析；可查看某任务结果，也可退出该筛选回到位置。后台实体继续按独立ID，不套目录继承。
- **清理工具**：常用系统配置、缓存和隐私操作的直接入口，同一注册能力也供模型按需调用。48项按类别/重要度排序，提供建议/全部、搜索、评分与勾选；状态、用途及影响直接可读。设置跳转与模拟执行分别标明，额外建议仍归当前任务，不另建任务/历史/确认体系。

导航切换保留位置、过滤和草案；返回不是取消、撤销或批准。一次展示最重要的目标、当前位置、必要状态和一个主操作，详情继续分层。

列表建议可原位附加一个专项入口，进入“清理工具”、软件流程或同任务的额外建议，再带结果返回原位置；关联、续接和执行后核验见[专项往返设计](CLEANUP_TOOLBOX_AND_EXTENSIONS.md#从已有建议进入专项清理再回到原现场)。明确以专项工具替代目录删除时，不能继续套用普通delete默认动作。专项往返随0.19实现，导航和逐层浏览在0.20接入，取舍见D056–D058。

## 打开一层，只读取一层

增加独立的只读“当前目录直接子项”枚举服务：分页/有界工作，返回名称、类型、条目大小、时间和文件身份；复用既有元数据构造与路径保护，**不调用递归扫描来伪装浏览**。进入子目录才读取其直接子项。后台扫描和模型调查可以复用同一批已有观察，避免浏览一次、分析又完整重读一次。

磁盘根入口不等于允许扫描整盘、上传正文或扩大某个旧任务的处理范围。目录枚举使用明确位置能力和稳定句柄/游标，排除链接循环及云占位取回；权限拒绝、卷拔出、变化、预算和取消分别返回状态。既有重解析点、凭据和保护规则继续应用，不能为浏览而绕过它们。

目录缓存与当前观察、模型建议是分开的层次。缓存有观察时间与版本；位置变化或签名不一致时失效，刷新只重读当前层。枚举完成仅说明这一层已读完，不证明全部子树已扫描；目录聚合大小未知时写“未统计”或“已观察下限”，不能显示成0。

按评分或名称筛选时，默认只筛已有观察，明确标出范围；不为找到全盘匹配项偷偷递归。需要更广结果时，由用户目标或模型调查明确启动有预算任务。

## 进展与建议表达

分别记录当前层枚举、子树观察和模型分析覆盖。未知总数不生成假百分比；可以显示“已查看N项、还有M个已知目录待看”，不能把M称为整盘剩余。继承项不计作逐项分析完成。

每个对象区分：未分析、直接建议、继承建议、明确跳过、调查后暂无建议及失效。继承标明上级、来源时间和“未逐项分析”；只有有效且明确涵盖子项的建议可传播。新浏览到的内容不自动扩写成旧模型已检查，超出原覆盖或来源过期时提示重核。颜色、进度和目录勾选不代替这些事实。

## 共用数据与操作主线

使用同一对象ID/文件身份、观察版本、建议来源和选择编译核心。任务结果保存对象引用及自身来源，不复制新文件对象；全局展示可关联最新有效建议，仍能回到各任务原始事实与旧来源，切换模型不能改署名。选择草案按来源/授权上下文保存，同一上下文的不同入口共用，别的任务不自动合并选择或复用批准。

共用流程：浏览/筛选 → 按需分析单项、勾选或目录 → 阅读建议 → 调整勾选与子项例外 → 编译冻结方案 → 明确确认 → 记录逐项结果。任务页只保存会话与对该工作区的引用，保留来源任务的授权边界；把旧任务结果映射到浏览器不授予其他目录动作资格。

普通文件也允许用户不经LLM直接选择删除意图。未评分、跳过或暂无建议不是强制先分析的理由；仍须取得实际对象身份/签名，核对真正保护、范围、目录完整性和明确动作，再进入相同预览/确认。当前只写模拟收据、实际释放0。未来真实删除必须另立执行门槛：可用回收站或备份、永久删除说明、逐项结果及恢复验证，不能通过换导航或按钮名开启。

## 历史实施顺序与持续验收

以下为0.20的实施顺序，导航、直接子项枚举、逐层状态和共享选择已交付；每次改动仍须按对应场景回归，不将本清单重新解释为全部尚未开发。

1. 提取共享路由、对象引用和选择核心，当前任务改为会话摘要加结果入口；保留0.18过滤、例外与冻结确认恢复。
2. 开发直接子项枚举和有界缓存，以自有大目录、无权限、链接、云占位、卷变化及取消夹具验证；实际文件浏览具备后再正式改名“文件清理”。
3. 接入逐层进展、直接/继承来源与旧覆盖核对，让常用目标进入同一工作区，复用已取得事实而非补扫全盘。
4. 验证两入口引用同一对象和选择、任务范围不外溢、跨页/目录例外、失效与重启恢复；再做暗浅/窄窗、键盘/文本选择、最终原生与数据恢复验收。

当前浏览枚举默认每页50项、最多100项；目录缓存最多8处、每处保留5000项、空闲120秒过期。每轮推进默认最多256条和0.15秒协作式预算，文件系统返回顺序不冒称全目录排序。游标绑定目录会话/位置变化，过期需刷新。精确接口见CONTRACT.json；上述边界不等于硬超时，最终程序验收按发布记录中的具体版本和场景理解。
